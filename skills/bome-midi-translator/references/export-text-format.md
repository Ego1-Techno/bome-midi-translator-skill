# Export Text format (File → Export Project As Text)

Human-readable format generated by MT Pro. Extension `.txt`.
**Easiest format for programmatic work** (see `scripts/bmtp_parser.py` and `scripts/bmtp_writer.py`). The signed `.bmtp` INI can also be hand-edited — see SKILL.md §4.

## Hierarchy

```
[state] Preset N: PresetName
[state] Translator N.M: TranslatorName
Options: <options>
Incoming: <trigger>
Rules:
  <rule line>
  ...
Outgoing: <action>
```

- `[x]` = active, `[ ]` = inactive
- N = preset index (0-based), M = translator index inside the preset

---

## Incoming — syntax

| Type | Export syntax |
|---|---|
| Raw MIDI | `MIDI B0 30 pp` (hex + vars) |
| Typed MIDI | `MIDI: Note On on ch.1 with note:64 and velocity:pp` |
| Timer trigger | `On timer "TimerName"` |
| Perform | `Perform "EventName"` |
| Project Open | `Project Open` |
| Project Close | `Project Close` |

## Options

```
Options: swallow
Options: swallow, stop
Options:            (empty if none)
```

## Rules — syntax

Same constructs as in MT Pro (see SKILL.md §2):
```
// comment
ga = 0
pp = qq * 128
if pp > 127 then pp = 127
if gb == 1 then exit rules, skip Outgoing Action
if gc != 0 then exit rules, execute Outgoing Action
Label "loop"
goto "loop"
skip next 2 rules
```

## Outgoing — syntax

| Type | Export syntax |
|---|---|
| Raw MIDI | `MIDI 90 pp 7F` |
| Typed Note On | `Note On on ch. 10 with note:111 (0x6F) and velocity:127 (0x7F), to port <portname>` |
| Typed CC | `Control Change on ch. 1 with controller:pp and value:qq, to port <portname>` |
| Pitch Bend | `Pitch Bend on ch. 1 with value:pp, to port <portname>` |
| SysEx | `MIDI F0 41 10 42 12 40 01 13 pp F7` |
| One-shot timer | `One-shot timer "TimerName": 300 ms delay` |
| Repeating timer | `Timer qq times "TimerName": 0 ms (initial delay: 0 ms)` |
| Infinite timer | `Start timer "PingHUI": every 1000 ms` |
| Perform | `Perform "EventName", pp, qq` |
| Keystroke | `Keystroke [TAB]` or `Keystrokes [SHIFT][TAB]` |
| Preset activate | `Activate Preset "PresetName"` |
| Variable Storage | `Load all variables from file 1` / `Save all variables to file 1` |
| None | `None` |

## Variable Storage (since 1.9.2)

In a dedicated section or at the end of the file:
```
ga=2
gb=24
gc=0
```

## Full example

```text
[x] Preset 0: Init
[x] Translator 0.0: Project Start - Load State
Options:
Incoming: Project Open
Rules:
  ga = 0
  gb = 0
Outgoing: Load all variables from file 1

[x] Preset 1: Fader MCU
[x] Translator 1.0: CC7 to Pitch Bend
Options: swallow
Incoming: MIDI B0 07 pp
Rules:
  // scale 7-bit → 14-bit
  qq = pp * 128
  rr = qq & 0x7F
  pp = qq >> 7
Outgoing: MIDI E0 rr pp

[ ] Translator 1.1: DEBUG log
Options: swallow
Incoming: MIDI B0 07 pp
Rules:
  // disabled
Outgoing: None
```
